# yukimura-site

真田幸村伝の公開ページ（2026-11-10 作成）。App Store Connect の「プライバシーポリシー URL」「サポート URL」と、特定商取引法に基づく表記に使う。
運営者の名前・屋号・メールアドレスは securelab-site・soroban-site と同じ。アプリは日本語だけなので、ページも日本語だけ。
アプリは通信も解析もしない（課金は Apple の仕組みだけ）。アプリを変えて情報の扱いが変わったら privacy.html も直す。
